## Superseded failures and remaining warnings

Initial builds failed on a missing AI insertion callback and unused editor variables. Dependency updates exposed mismatched Prisma generator/client versions and changed Nodemailer type exports. These failures were repaired and builds rerun. Initial frontend/admin/website lint errors were repaired without disabling the rules.

Frontend bundle is about 1.63 MB uncompressed; admin about 0.89 MB. Vite warns about chunk sizes. Lottie includes an eval warning; this requires CSP/bundle review before deployment. Browser dependency `use client` directives were ignored by Vite during bundling. Hook warnings remain visible rather than suppressed.
